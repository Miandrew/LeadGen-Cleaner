PHASE 3 — Slug generation
Your companies table has a slug column but it's probably empty. Slugs are what make URLs like /directory/abc-janitorial-dallas-tx. Paste this into Replit Agent after Phase 2:

Write a script scripts/generate-slugs.ts that:

Reads all companies from Supabase where slug is null or empty
Generates a slug for each one from name + city + state: lowercase, spaces to hyphens, remove special characters
Example: "ABC Janitorial" in "Dallas, TX" → abc-janitorial-dallas-tx
If a slug already exists append -2, -3 etc to make it unique
Updates each company in Supabase with their slug
Runs as: npx tsx scripts/generate-slugs.ts
