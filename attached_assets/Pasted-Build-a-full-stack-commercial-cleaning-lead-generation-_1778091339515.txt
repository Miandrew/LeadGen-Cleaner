Build a full-stack commercial cleaning lead generation directory called 
CommercialCleaningNearMe.com.

Tech stack: Next.js 14 with App Router, TypeScript, Tailwind CSS, Supabase, 
Stripe, Resend. Deploy target is Vercel but build locally first.

---

BUSINESS LOGIC

A facility manager visits the site, searches for cleaning companies in their 
city, selects up to 3 companies, and submits a free quote request. All 
selected companies receive an email with partial lead info. Each company pays 
$35 to unlock full contact details (name, phone, email). One flat price, no 
tiers. This is the core revenue mechanic.

Secondary revenue: monthly subscriptions where cleaning companies pay a flat 
rate and leads auto-deliver to them without additional payment per lead.

Also create a Supabase RPC function:

create or replace function decrement_leads(p_company_id uuid)
returns int as $$
declare
  current_remaining int;
begin
  select leads_remaining into current_remaining
  from users where company_id = p_company_id;
  if current_remaining > 0 then
    update users set leads_remaining = leads_remaining - 1
    where company_id = p_company_id;
    return current_remaining - 1;
  else
    return -1;
  end if;
end;
$$ language plpgsql;

import { createClient } from '@supabase/supabase-js'
import fs from 'fs'
import path from 'path'

const supabase = createClient(
  process.env.NEXT_PUBLIC_SUPABASE_URL!,
  process.env.SUPABASE_SERVICE_ROLE_KEY!
)

function generateSlug(name: string, city: string): string {
  return `${name}-${city}`
    .toLowerCase()
    .replace(/[^a-z0-9\s-]/g, '')
    .replace(/\s+/g, '-')
    .replace(/-+/g, '-')
    .trim()
}

async function importCSV(filePath: string) {
  const content = fs.readFileSync(filePath, 'utf-8')
  const lines = content.split('\n')
  const headers = lines[0].split(',').map(h => h.trim().replace(/"/g, ''))
  
  let inserted = 0
  let skipped = 0

  for (let i = 1; i < lines.length; i++) {
    if (!lines[i].trim()) continue
    
    const values = lines[i].split(',').map(v => v.trim().replace(/"/g, ''))
    const row: any = {}
    headers.forEach((h, idx) => { row[h] = values[idx] || '' })

    if (!row.name && !row.city) { skipped++; continue }

    const slug = generateSlug(row.name || '', row.city || '')

    const { data: existing } = await supabase
      .from('companies')
      .select('id')
      .eq('slug', slug)
      .single()

    if (existing) { skipped++; continue }

    const services = row.services_clean 
      ? row.services_clean.split(',').map((s: string) => s.trim()).filter(Boolean)
      : []

    const { data: company, error } = await supabase
      .from('companies')
      .insert({
        name: row.name,
        slug,
        city: row.city,
        state: row.state,
        phone: row.phone,
        email: row.email,
        website: row.website,
        address: row.address,
        rating: parseFloat(row.rating) || null,
        review_count: parseInt(row.review_count) || 0,
        place_id: row.place_id,
        services,
        active: true,
      })
      .select()
      .single()

    if (error) { console.error(`Error inserting ${row.name}:`, error); skipped++; continue }

    inserted++
    if (inserted % 100 === 0) console.log(`Inserted: ${inserted}`)
  }

  console.log(`Done. Inserted: ${inserted}, Skipped: ${skipped}`)
}

importCSV(process.argv[2] || 'master_clean.csv')

--- api/leads/create/route.ts ---

POST handler.

1. Parse request body for all lead fields + selected_company_ids array.

2. Duplicate check: query leads table where contact_email matches AND 
   created_at > now() - interval '7 days'. If found, return 
   { success: true, duplicate: true } — do not insert.

3. Validate required fields: service_type, city, state, contact_name, 
   contact_email, contact_phone, business_name, selected_company_ids 
   (must be array with 1-3 items).

4. Insert lead to Supabase leads table. Return lead ID.

5. Send 3 emails in parallel via Promise.all:

   Email A — To each company in selected_company_ids:
   Query company email from companies table. Skip if no email or do_not_email=true.
   From: leads@commercialcleaningnearme.com
   Subject: "New Lead — [service_type] in [city], [state]"
   HTML body:
   - Header: "You have a new lead on CommercialCleaningNearMe.com"
   - Details card: Location, Service, Building Type, Building Size, Frequency
   - Note: "This lead was sent to [X] companies total."
   - Big CTA button: "Unlock Full Contact Details — $35"
     href: NEXT_PUBLIC_SITE_URL/unlock-lead/[lead_id]/[company_id]
   - Footer: "Lead expires in 72 hours."

   Email B — Admin notification to ADMIN_EMAIL:
   Subject: "New Lead — [service] in [city] [state]"
   Body: all lead details, company names notified, timestamp.

   Email C — Confirmation to contact_email:
   Subject: "Your quote request has been sent"
   Body: "Hi [first name from contact_name], your request for [service_type] 
   in [city] has been sent to [X] cleaning companies. They will contact you 
   within 24 hours."

6. If any email fails, log error but DO NOT fail the request. Lead saves 
   regardless of email status.

7. Return { success: true, leadId: lead.id }

--- lib/resend.ts ---

import { Resend } from 'resend'
export const resend = new Resend(process.env.RESEND_API_KEY)

export async function sendEmail(to: string, subject: string, html: string) {
  try {
    await resend.emails.send({
      from: 'CommercialCleaningNearMe.com <leads@commercialcleaningnearme.com>',
      to,
      subject,
      html
    })
  } catch (error) {
    console.error('Email send failed:', error)
  }
}

--- FINAL NOTES ---

1. All Supabase queries use supabaseAdmin (service role) in API routes and 
   server components. Use supabase (anon) in client components.

2. All API routes that modify data should verify the user is authenticated 
   unless explicitly noted (webhook routes verify Stripe signature instead).

3. The stripe_payment_id unique constraint on lead_purchases is the 
   idempotency mechanism — if a Stripe webhook fires twice for the same 
   payment, the second upsert silently does nothing.

4. The email_sequences unique constraint (company_id, sequence_name) 
   prevents any company from receiving the same automated email twice, 
   regardless of how many times the cron runs.

5. For the admin rate limiter, use a module-level Map — in-memory is fine 
   since this is a single-server admin route.

6. Places API photos must ALWAYS write to Supabase before rendering. 
   Never fire-and-forget. Never re-fetch if image_urls is already populated.

7. Make the site look genuinely professional. Navy #1B3A6B and blue #2563EB 
   throughout. Proper spacing, shadows, hover states on all interactive 
   elements. The design should feel like a trusted B2B product, not a 
   side project.

Build every file completely. No placeholders. No TODOs. 
Working code in every file.
